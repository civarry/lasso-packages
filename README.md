# Lasso packages

Packages for [Lasso](https://github.com/civarry/lasso-app), the Mac app that lets you draw a box around
anything on screen and copy, translate or ask about it. A package adds to Lasso (a search source, a
toolbar button, a chat command, a Send to target, a tool for its models) or changes it (its prompts,
toolbar and suggestions).

**To add one:** in Lasso, open Settings › Packages › **Browse…**, pick a package, read what it can reach,
and click Add. A link like `lasso://install?id=study-tools` opens Browse at that package; nothing is ever
installed without your click.

## What's here

| Package | What it does | Sends data to |
|---|---|---|
| [Tavily](packages/tavily) | Web search results from Tavily | api.tavily.com (your key) |
| [SerpApi](packages/serpapi) | Google results when search comes back thin | serpapi.com (your key) |
| [Study tools](packages/study-tools) | Explain simply, and flashcards | Your chosen model only |
| [Track package](packages/track-package) | Opens tracking for a parcel number you lasso | parcelsapp.com (opens a page) |
| [Table to CSV](packages/table-to-csv) | A table you lasso as a CSV file | Nothing: a sandboxed script |
| [My notes](packages/notes-search) | Searches a folder of your notes | Nothing: a sandboxed script |
| [Run Python](packages/python-runner) | /run and /draw: runs the Python in chat, draws turtle pictures | Nothing: a sandboxed script |
| [Writing Kit](packages/writing-kit) | Bullet-point summaries, a calmer toolbar | Nothing: it changes Lasso itself |

## How it's checked

Every pull request is built and checked by CI with `lasso-pkg`, built from Lasso's own source, so it runs
exactly the checks Lasso runs before installing:

- every rule of the [package format](https://github.com/civarry/lasso-app/blob/main/docs/PACKAGES.md);
- the folder is named like the package's id, and the README says what it sends where and what it needs;
- a changed package's version went up;
- each script's `test` runs, in Lasso's sandbox.

Then a maintainer reads every script line by line before merging. **Merging is publishing:** CI writes
`index.json` and a download for each package in `dist/`. Lasso refuses a download whose SHA-256 doesn't
match `index.json`.

## Layout

```
packages/<id>/   lasso.json, README.md, scripts/…   one package
index.json       generated by CI, never edited by hand
dist/            generated downloads (.lassopkg)
schema/v1.json   JSON Schema for editors
templates/       what "New Package" and lasso-pkg new start from
```
