# Tavily

Adds Tavily's web search results to Lasso's search (chat and Identify).

- **Sends:** your search queries to `api.tavily.com`, with your Tavily API key.
- **Needs:** a Tavily API key (free tier available at https://app.tavily.com). It's kept in your Keychain.
- **Limits:** stops at the free tier's monthly allowance.

Also built into Lasso: Settings › Packages › + › Built into Lasso.
