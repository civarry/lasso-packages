# SerpApi

Adds Google results through SerpApi to Lasso's search, when results are thin.

- **Sends:** your search queries to `serpapi.com`, with your SerpApi key.
- **Needs:** a SerpApi API key (free tier available at https://serpapi.com). It's kept in your Keychain.
- **Limits:** stops at the free tier's monthly allowance.

Also built into Lasso: Settings › Packages › + › Built into Lasso.
