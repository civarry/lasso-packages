# My notes

Adds a folder of Markdown or text notes to Lasso's search, so chat can answer from your own notes.

- **Sends:** nothing. It runs `scripts/search.py` on your Mac, in Lasso's sandbox, with no internet. It
  can read only the notes folder you choose in its settings.
- **Needs:** a notes folder, and Python 3 (`/usr/bin/python3`).
