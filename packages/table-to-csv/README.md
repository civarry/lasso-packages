# Table to CSV

A toolbar button that turns a table you lasso into a CSV file, saved in `~/LassoWorkspace/table-to-csv/`.

- **Sends:** nothing. It runs `scripts/to-csv.py` on your Mac, in Lasso's sandbox, with no internet.
- **Needs:** Python 3 (`/usr/bin/python3`; macOS offers to install the command-line tools the first time).
