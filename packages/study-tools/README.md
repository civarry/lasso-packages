# Study tools

Two toolbar buttons for what you lasso, and `/explain` in chat:

- **Explain simply:** explains it so a 10-year-old understands, in at most 5 sentences.
- **Flashcards:** up to 8 question-and-answer cards from longer text.

- **Sends:** the text you run it on to the model you chose in Lasso's Settings, and nowhere else. With a
  model on your Mac, it works offline.
- **Needs:** nothing.
